🎯 Razorpay Payment Integration

This file demonstrates how to call the backend endpoints for Razorpay payment integration.

Step 1: Validate Checkout

Call GET /api/cart/validateCheckout to check if cart is ready for checkout

Step 2: Confirm Checkout & Create Order

Call POST /api/cart/checkout/confirm to create order and get Razorpay order ID

Step 3: Open Razorpay Checkout Modal

Frontend opens Razorpay checkout using the razorpayOrderId from Step 2

⚠️ Note: You need Razorpay public key and order details from Step 2
